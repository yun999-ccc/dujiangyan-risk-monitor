## 地图操作

- 「拖动旋转」：左键或单指改变观察方向；右键始终平移。
- 「拖动平移」：左键或单指移动观察中心。俯视地图默认使用平移，不锁死左键拖动。
- 滚轮向指针所在位置缩放；手机双指同时移动和缩放。
- 双击地面、房屋或河面，改变观察中心并靠近；保留当前观察方向。
- 先点击地图，再用方向键平移；地图外保留正常网页滚动。
- 区域最近观察距离约12m，局部河段约8m；实际地形和建筑数据精度没有因此提高。相机近裁剪面随距离调整，减少近景被截断。
- 重复选择同一个三维/俯视按钮，或重复选择已打开的积水项，不重置观察角度。一键恢复总览仍保留。切换区域或重建假定河槽会重新取景。

## 数据真实性

当前首项整改是几何数据核查，见[核查结果与补测要求](docs/geometry-evidence.md)。地图下方可查看数据依据；进入河谷演算可对比公开DEM、假定地形、修改分布和网格剖面，并导出当前参数与差值。**关键河床、堤岸等资料尚未齐备，真实几何未通过验收。**

![当前假定地形与公开DEM的修改量和剖面对比](assets/geometry-review.png)

- 高程：Mapzen Terrain Tiles / AWS Open Data，Terrarium，513×513重采样；展示范围103.46—103.73E、30.94—31.17N。区域总览垂直夸张1.8倍，局部河段为1∶1；非工程测量。
- 水系、道路、建筑、部分用地轮廓：OpenStreetMap API 0.6，2026-10-10取得；仅覆盖两个矩形查询片区，可能不完整。
- 建筑：420条公开轮廓，缺少高度时假定12米。没有真实立面或屋顶数据。
- 黄央沟沟口：按2014年《都江堰市龙池镇黄央沟泥石流特征与防治工程效果分析》的文献坐标定位；坐标基准未注明，定位不能视为测绘级准确。只代表历史案例沟口，不是当前危险范围。
- 其余节点：示意布置。全部读数、阈值与风险状态均为模拟，不是实时预警。
- 预设情景与自动推进用于交互展示，不是经校准的灾害模型。不能推断安全通行或真实灾害概率。
- 道路与河道显示宽度为示意；地形按高程和坡度着色，使用坡面明暗与颗粒材质；装饰树群不代表真实植被位置、数量或尺寸。

### 模拟实验台使用

1. 手动保持：选择风险，使用数字输入、滑杆及现场证据选项。开始模拟只推进时钟，主参数保持不变。
2. 情景轨迹：展开“所选参数的变化轨迹”，勾选并输入结束目标；设置1—120分钟时长，点击“生成情景 / 应用轨迹”。
3. 播放或拖动时间线；回到起点可重播。手动改主参数会关闭该项轨迹，改为全程固定的新值；也会关闭该积水节点的自动涨退、或泥石流节点的共享降雨。
4. 积水可选择按正负涨退速度演算。片区降雨从起始值线性变为结束值，累计量按模拟秒积分；只有勾选关联的泥石流读取雨强，关联滑坡读取累计雨量背景而不改变位移。积水只展示背景。
5. 故障冻结读数；缺失、过期及到期模拟雷电信号显示未知。结冰、烟火等模拟巡查记录必须手动更新，不随指标回落自动消失。

阈值全部为可修改的演示配置；冰雪还结合路面与巡查证据。未接入真实传感器、官方预警或经过验证的灾害模型。湿度、活动时长等背景条件展示在判断依据中，不计算医学风险或正式火险指数。地图选中节点显示读数与核查状态，圈面仍为示意。

播放倍率仅改变时间推进；1×下1现实秒对应1模拟秒。过程模型使用模拟秒计算，不额外乘速度。状态使用本浏览器localStorage v2，刷新自动暂停；未实现跨设备共享后端。导出JSON包含模拟状态、规则版本、轨迹基线和操作记录，可在代码中重放（尚无网页导入功能）。

山区道路显示优化：以道路采样高程的中位数划分展示样式（约950米以上），采用灰绿色路面与窄路缘；山区路段采用灰绿色，城区路段深灰色；山区不生成示意中心标线。仅缺少宽度和车道数的次级道路限制估计展示宽度；OSM明确宽度与车道数仍优先使用。路面按公开DEM网格边界及对角线拆分，转弯采用有限斜接。此高程划分仅用于沙盘配色，不代表实际路面材料或山区行政边界。

### 龙溪河局部河段：水过程、道路依据与处置演练

![城区房屋与公路视图](assets/city-context.png)

原全区域的420个公开建筑轮廓模型与路网仍保留。河段面板可点击「查看城区房屋与公路」，或通过 `?area=city`直接查看城区；选择区域视图会恢复地形与设施图层。局部河段独立标明其0条公开建筑记录和8条道路，未将其他区域的房屋搬进计算区。山路在局部视图采用较清晰的灰绿配色与浅色路缘，配色不代表实测路面材料。

选择积水默认进入河段演算，或打开网址添加 `?river=1`；`&stage=900`直接查看默认条件15分钟。控制峰值来水、局部降雨、假定排水和下游参考水深，展开可改来水过程与假定河槽。修改有效输入后重算当前时刻，计算期间保留上次完成的地图并明确标注。首次进入显示1分钟暂停结果；刷新恢复上次完成时刻和参数并暂停。可以切换独立的「教学积水近景」，或通过 `?street=1`直接进入原手动教学模式。

公开来源：打包DEM、OSM龙溪河中心线（way 219484805）与8条邻近道路要素。计算域约1.536×1.536km，96×96单元、16m插值网格，不增加原约50m DEM的测绘精度。该域公开建筑轮廓为0条，不能据此认定现场没有房屋。默认假定河槽宽48m、深3m，去除局部反坡并以岸外96m过渡衔接公开DEM；修改最大量约50.917m，须参见几何核查。整个流域、上游汇水、支流与管网没有建模。

模型为独立实现的局部惯性近似（`local-inertial-v3`）：面通量包含局部加速度、水面坡降和曼宁阻力，没有完整对流动量、泥沙、溃坝冲击或桥孔计算。实际步长受稳定条件限制，最大0.0625s；保留最后保护性供水限流并报告累计数量，交换水量守恒。下游参考水深允许出流和倒灌，分别计入收支，其余边界封闭。降雨有效比例进入非建筑网格，道路排水按已有水量分配，不是经核实的真实管网。

[公式背景参考](https://gmd.copernicus.org/articles/16/2415/2023/gmd-16-2415-2023.html)。本网页不是LISFLOOD-FP或HEC-RAS软件。界面标出快速流单元的适用性缺口。静水零通量、均匀流曼宁解析关系、非负水深、水量收支、退水、倒灌和确定性回放有自动检查；默认900秒条件比较0.0625s与0.03125s的逐网格水深最大差异须小于5cm、平均差小于1mm。这是本模型的时间步长检查，不是空间收敛或现场精度证明。

局部三维水面、地形与计算均采用1∶1高程，区域总览仍为1.8倍展示。蓝色色带对应演算水深，水面和统计统一采用5cm阈值；岸线为网格插值显示。流线按照估计速度和播放时钟移动，没有额外×10位移；箭头长度和宽度为辨认用视觉比例。10×、30×、60×为期望播放倍率，计算与设备性能可能降低实际墙钟推进速度。暂停停止水面过渡及流线，减少动态设备默认关闭微波纹和动态流线。

六个观察位置可点击、定位和查看水深、估计流速、首次达到5cm、持续时间及已经历峰值。观察点按计算步记录，图表每30模拟秒采样。道路过程每5模拟秒采样并另纳入当前结果，可能遗漏采样之间的短时变化。点击道路按钮定位其最深采样网格；橙色细线只表示中心线附近网格积水，不代表实测路面宽度。带桥梁标签的要素显示桥面高程未知，不将下方地面水深当成桥面淹没。其他道路是否存在未标记桥梁也尚未核实。

积水事件自动包含路段ID、坐标、模拟时刻、依据、水深与估计流速。可进行「确认模拟事件 → 安排模拟巡查 → 填写处置反馈」；任务完成不清除积水、不宣称道路安全。记录只保存在本浏览器，没有向人员发送消息或跨设备同步。修改条件或回放到更早时刻清空该情景处置记录；导出JSON包含版本化事件及过程数组，供后续网页接入，见[联动接口与验证说明](docs/river-workflow.md)。当前无法评估真实居民点、人数或可靠绕行路线，界面明确显示资料缺口。

可「保存当前时刻为对照」，改变输入后在同一模拟时刻比较岸外覆盖、道路E水深和排出水量。对照只保留在当前页面并随导出保存，不是实测改善率。数值核查可另运行0.125s、0.0625s、0.03125s三个最大步长，以最细组作数值比较参考，不能视为真值。

### 雷电事件层

选择「雷电」或网址添加 `&lightning=1`，查看主沙盘中的云对地、云间通道与分叉。频率（0—30次/分钟）、过程时长（1—60分钟）、类型、区域、参考距离、视觉档位和固定随机种子控制事件计划。事件数为频率×分钟向下取整，事件在过程内均匀分布并加入确定性时间抖动；不是真实雷电的概率或探测模型。相同配置与种子重现同一事件列表。云对地位置避让公开建筑外接范围及约30m余量；数据不完整，此操作不证明真实位置安全。没有可用位置时标为不可显示，不编造落点。距离指落点或云间主通道起点，不是通道全部分叉的最大半径。

频率与时长不改变外部预警。预警仍为人工模拟信号，信息有效期与雷暴过程时长分开；过程结束不清除预警，事件回放不倒退预警时钟。预警信息过期显示未知而不是无预警。现场人数移到应急面板，仅与待转移人数、户外活动和负责人确认生成任务说明，不影响事件或预警。人员修改后需要重新确认，不推断安全路线与建筑防雷能力。

通道、云层高度、线宽与辉光均为视觉示意，不表示实测电流。动态事件仅局部显示350ms、没有全屏闪白；全部事件记录保留，加速播放时动态显示最多每2秒一次，可关闭动态改用静态通道。单次手动演示不计入计划频率。系统减少动态效果时默认关闭闪光；用户可以明确选择开启。暂停停止事件调度，显示静态形态；未知事件状态停止新增。刷新后暂停，恢复配置、过程位置、预警时钟与应急状态；计划事件由种子重建，手动形态演示记录仅保留当前页面会话。计时依据前台动画时钟，低帧率和后台标签页会降低墙钟推进速度，不保证播放倍率等于墙钟时间。

### 六类变量驱动现象层

冰雪、大风、高温、森林火险、滑坡、泥石流新增原主沙盘中的现象层；选择风险自动定位近景，也可点击下方「定位效果」。近景相机按周围DEM采样避开山体遮挡。环境变量沿用右侧输入，效果面板显示输入、现场条件、图例、独立的效果时间线和假定参数。网址可添加 `&risk=ice`、`&risk=wind` 等直接选择风险。

| 风险 | 输入与效果对应 | 边界 |
| --- | --- | --- |
| 冰雪结冰 | 积雪记录与假定厚度、覆盖率改变雪面；发现结冰显示冰面，或主动开启形成示意后在≤0℃且有水/积雪的假定条件下显示冰面 | 低温与湿度不自动确认结冰；道路走向取OSM，路面高程、监测点、覆盖率与厚度未实测，湿度仅为背景，动态为反光示意、不计算形成速度 |
| 大风 | 风速映射风迹长度/移动与旗帜摆动；来向角决定吹去方向；持续时间限制本次效果过程 | 0风速或0时长不生成风迹；不是风场、结构受力或倒塌计算 |
