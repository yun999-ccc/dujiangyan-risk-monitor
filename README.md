## 数据真实性

当前首项整改是几何数据核查，见[核查结果与补测要求](docs/geometry-evidence.md)。地图下方可查看数据依据；进入河谷演算可对比公开DEM、假定地形、修改分布和网格剖面，并导出当前参数与差值。**关键河床、堤岸等资料尚未齐备，真实几何未通过验收。**

![当前假定地形与公开DEM的修改量和剖面对比](assets/geometry-review.png)

- 高程：Mapzen Terrain Tiles / AWS Open Data，Terrarium，513×513重采样；展示范围103.46—103.73E、30.94—31.17N。垂直夸张1.8倍，非工程测量。
- 水系、道路、建筑、部分用地轮廓：OpenStreetMap API 0.6，2026-10-10取得；仅覆盖两个矩形查询片区，可能不完整。
- 建筑：420条公开轮廓，缺少高度时假定12米。没有真实立面或屋顶数据。
- 黄央沟沟口：按2014年《都江堰市龙池镇黄央沟泥石流特征与防治工程效果分析》的文献坐标定位；坐标基准未注明，定位不能视为测绘级准确。只代表历史案例沟口，不是当前危险范围。
- 其余节点：示意布置。全部读数、阈值与风险状态均为模拟，不是实时预警。
- 预设情景与自动推进用于交互展示，不是经校准的灾害模型。不能推断安全通行或真实灾害概率。
- 道路与河道显示宽度为示意；地形按高程和坡度着色，使用坡面明暗与颗粒材质；装饰树群不代表真实植被位置、数量或尺寸。

### 模拟实验台使用

1. 手动保持：选择风险，使用数字输入、滑杆及现场证据选项。开始模拟只推进时钟，主参数保持不变。
2. 情景轨迹：展开“所选参数的变化轨迹”，勾选并输入结束目标；设置1—120分钟时长，点击“生成情景 / 应用轨迹”。
3. 播放或拖动时间线；回到起点可重播。手动改主参数会关闭该项轨迹，改为全程固定的新值；也会关闭该积水节点的自动涨退、或泥石流节点的共享降雨。
4. 积水可选择按正负涨退速度演算。片区降雨从起始值线性变为结束值，累计量按模拟秒积分；只有勾选关联的泥石流读取雨强，关联滑坡读取累计雨量背景而不改变位移。积水只展示背景。
5. 故障冻结读数；缺失、过期及到期模拟雷电信号显示未知。结冰、烟火等模拟巡查记录必须手动更新，不随指标回落自动消失。

阈值全部为可修改的演示配置；冰雪还结合路面与巡查证据。未接入真实传感器、官方预警或经过验证的灾害模型。湿度、活动时长等背景条件展示在判断依据中，不计算医学风险或正式火险指数。地图选中节点显示读数与核查状态，圈面仍为示意。

播放倍率仅改变时间推进；1×下1现实秒对应1模拟秒。过程模型使用模拟秒计算，不额外乘速度。状态使用本浏览器localStorage v2，刷新自动暂停；未实现跨设备共享后端。导出JSON包含模拟状态、规则版本、轨迹基线和操作记录，可在代码中重放（尚无网页导入功能）。

山区道路显示优化：以道路采样高程的中位数划分展示样式（约950米以上），采用灰绿色路面与窄路缘；跨越平地与山谷的道路随高程渐变配色，取消高程较高区段的示意中心标线。仅缺少宽度和车道数的次级道路限制估计展示宽度；OSM明确宽度与车道数仍优先使用。路面内部自适应细分贴合三角地形，转弯采用有限斜接。此高程划分仅用于沙盘配色，不代表实际路面材料或山区行政边界。

### 道路积水近景

选择积水后显示独立可旋转的三维道路近景，0—60 cm 连续水深与主参数双向联动。局部地面为设计的低洼道路、抬高人行道及六栋示意建筑；平面水面依局部高差裁剪，建筑内部不计入覆盖面积。面积按0.25米网格估算，仅针对本示意模型，非区域淹没预测。水面微波纹与降雨涟漪可单独关闭；雨强为零或未启用片区降雨时无涟漪。没有流速、排水或真实建筑入口模型。数据异常保存最近有效水深，刷新后仍保留并标记未知。暂停停止水深演算，视觉微波纹可继续或关闭；减少动态效果的设备默认关闭微波纹。

### 龙溪河局部河谷演算

在区域沙盘点击「河谷演算」，或打开网址时添加 `&river=1`，切换主沙盘为龙溪河黄央沟邻近片区的局部计算地形。可以修改起始、峰值、结束来水量，降雨、有效降雨比例、道路排水能力与受阻状态，并查看流动、漫岸和退水阶段。手动水深输入在此模式下隐藏，其他七类风险与原道路积水近景保留；选择其他风险自动退出河谷模式。

公开来源：原DEM和OSM龙溪河中心线（way 219484805）与邻近8条道路要素。计算域约1.536×1.536 km，96×96单元、16 m插值网格，未增加原始测绘精度。该域公开建筑轮廓为0条，不代表真实没有建筑。假定断面默认宽48 m、深3 m，沿中心线平滑并去除反坡，岸外96 m内设计缓坡衔接原DEM。计算和局部三维展示共用修改后的网格；显示高程×1.8，计算长度、面积、时间、水量均使用原始SI单位。道路观察点为公开道路附近网格中心（约103.56158°E、31.07218°N），非现场传感器。

模型：独立实现的显式扩散波近似，面通量使用宽浅水曼宁关系，由水面坡降驱动，交换单元体积严格守恒。忽略完整惯性动量、泥沙、管网和溃坝冲击。计算步长≤0.5 s；每步供水限流至单元水量的35%，保持非负；限流会影响流速、洪峰和结果，界面报告受限面数量，未做实测校准或网格收敛验证。下游是固定参考水深、只出不进的边界，其他边界封闭。有效降雨按比例进入非建筑单元，其余记为假定损失；道路排水在有水道路单元分配，不超过可用水量。

[扩散波理论说明（HEC-RAS）](https://www.hec.usace.army.mil/confluence/rasdocs/ras1dtechref/6.6/theoretical-basis-for-one-dimensional-and-two-dimensional-hydrodynamic-calculations/2d-unsteady-flow-hydrodynamics/hydraulic-equations/diffusion-wave-approximation-to-the-shallow-water-equations)。本网页不是HEC-RAS软件，也不具有该工程软件的精度与验证范围。

流线按面通量估计的方向与速度移动，动画位移×10，独立于水量演算时间，可关闭。播放10×、30×、60×指每个推进周期请求对应模拟秒数，计算中不会追加重叠请求；设备较慢时墙钟推进可能低于设置倍率，界面时间为实际完成的模拟时间。暂停冻结已完成结果，回放从同一初始状态重算。峰值没有当地频率或重现期意义；阶段按钮只是固定时间定位，修改参数后不保证该时刻仍漫岸。刷新后河谷演算重新从起点开始；导出保存本次参数、网格深度和流速、收支与边界说明。

### 雷电事件层

选择「雷电」或网址添加 `&lightning=1`，查看主沙盘中的云对地、云间通道与分叉。频率（0—30次/分钟）、过程时长（1—60分钟）、类型、区域、参考距离、视觉档位和固定随机种子控制事件计划。事件数为频率×分钟向下取整，事件在过程内均匀分布并加入确定性时间抖动；不是真实雷电的概率或探测模型。相同配置与种子重现同一事件列表。云对地位置避让公开建筑外接范围及约30m余量；数据不完整，此操作不证明真实位置安全。没有可用位置时标为不可显示，不编造落点。距离指落点或云间主通道起点，不是通道全部分叉的最大半径。

频率与时长不改变外部预警。预警仍为人工模拟信号，信息有效期与雷暴过程时长分开；过程结束不清除预警，事件回放不倒退预警时钟。预警信息过期显示未知而不是无预警。现场人数移到应急面板，仅与待转移人数、户外活动和负责人确认生成任务说明，不影响事件或预警。人员修改后需要重新确认，不推断安全路线与建筑防雷能力。

通道、云层高度、线宽与辉光均为视觉示意，不表示实测电流。动态事件仅局部显示350ms、没有全屏闪白；全部事件记录保留，加速播放时动态显示最多每2秒一次，可关闭动态改用静态通道。单次手动演示不计入计划频率。系统减少动态效果时默认关闭闪光；用户可以明确选择开启。暂停停止事件调度，显示静态形态；未知事件状态停止新增。刷新后暂停，恢复配置、过程位置、预警时钟与应急状态；计划事件由种子重建，手动形态演示记录仅保留当前页面会话。计时依据前台动画时钟，低帧率和后台标签页会降低墙钟推进速度，不保证播放倍率等于墙钟时间。

### 六类变量驱动现象层

冰雪、大风、高温、森林火险、滑坡、泥石流新增原主沙盘中的现象层；选择风险自动定位近景，也可点击下方「定位效果」。近景相机按周围DEM采样避开山体遮挡。环境变量沿用右侧输入，效果面板显示输入、现场条件、图例、独立的效果时间线和假定参数。网址可添加 `&risk=ice`、`&risk=wind` 等直接选择风险。

| 风险 | 输入与效果对应 | 边界 |
| --- | --- | --- |
| 冰雪结冰 | 积雪记录与假定厚度、覆盖率改变雪面；发现结冰显示冰面，或主动开启形成示意后在≤0℃且有水/积雪的假定条件下显示冰面 | 低温与湿度不自动确认结冰；路段、覆盖率与厚度均为假定，湿度仅为背景，动态为反光示意、不计算形成速度 |
| 大风 | 风速映射风迹长度/移动与旗帜摆动；来向角决定吹去方向；持续时间限制本次效果过程 | 0风速或0时长不生成风迹；不是风场、结构受力或倒塌计算 |

| 滑坡 | 监测位移变化映射放大的箭头；裂缝/掉块记录显示裂缝；独立手动距离和时长控制土体运动示意 | 不从降雨或位移阈值启动运动；土体、裂缝均为符号化示意，不改变背景山体或评估稳定性 |

滑坡与泥石流通过「启动…示意」按钮或主动拖动效果时间线启用；常态或高风险预设只改变监测输入，不自动启动灾害运动。路径沿局部DEM的16个候选方向逐步寻找下坡（12m采样间隔，不增加原始测绘精度），到低点停止；未核实黄央沟真实沟道，不表示真实地质灾害路径或影响范围。界面报告采样路径长度和泥流前沿；前沿到路径末端后不继续延伸，循环颗粒仅表达流向。公共水系有夸张抬高的示意绘制，泥流采用优先显示的贴地覆盖图层保持辨识，不表示真实泥流厚度或已淹没河流。

效果播放、监测轨迹和雷电过程使用各自时间线；效果回放不会改变监测读数、清除巡查记录或预警。关闭动态停止效果过程，仍可拖动时间线查看静态阶段。切换风险、刷新或数据未知会暂停；未知状态保留最后有效示意并标注，若无有效快照则不生成现象。配置、静态阶段与最后有效快照保存在原localStorage v2，并包含在导出JSON中。系统减少动态效果时默认关闭动态。前台动画时钟每帧最多推进0.1秒，低帧率和后台暂停会影响墙钟速度，不保证实时倍率。未增加跨设备共享后端。

### 画面清晰度与可见性修复

按桌面1536×1080、手机390×844（2×像素密度）检查八类风险、建筑、区域总览、道路浅水/深水与河谷，共26个视图。检查图像载入、渲染错误、遮挡、模型占画面比例、标注碰撞和横向溢出；这是浏览器视口检查，不等于所有真实手机或显卡验证。

- 画布与支撑信息分开：区域按钮、图层切换移到画布下方，图例和模型说明收进可展开区；现象说明停靠左上，模型中心保持可见。总览标注避让标题、工具和其他标注，空间不足时隐藏次要标注。
- 三个渲染器的像素密度上限统一为2×。地形材质颗粒按屏幕采样宽度衰减，减少缩远后的纹理闪烁；这不新增地形精度。近景建筑阴影随取景范围调整，装饰树群比例减小且不投射巨大阴影。树群仍为装饰，尺寸不代表实测植被。
- 六类现象按自身范围取景；滑移与泥流依据已有示意路径包围范围取景。积雪改为贴地的浅白斑块，泥流相邻段共享边界并使用棕色细纹，滑移土体增加顶面、侧面与碎块且顺应显示地形。现象线改为可辨识的细管几何；线宽仍为视觉夸张。
- 单次闪电、配置应用和静态阶段自动取景；云间形态从通道侧面观察，避免水平放电被透视压缩成类似向地面的通道。运行中的雷暴保持区域视角，不逐次追随随机事件。通道宽度为视觉表现，静态近景隐藏无关的观测区云团。
- WebGL不可用时，区域沙盘显示由原公开DEM生成的二维高程图与可选风险点，显示明确的三维不可用说明；不会将二维图冒充三维建模。独立水面近景与河谷渲染仍需WebGL，不可用时保留参数与说明。

新增检查覆盖标注避让、手机遮挡、云间横向形态与完整取景、高分屏画布密度以及WebGL降级。`scripts/audit-visuals.mjs`可重现26个视图并输出渲染错误与尺寸报告；输出在忽略的artifacts目录，运行需可用Chrome及本地预览或MONITOR_BASE_URL。烟雾保留自然柔边；柔和阴影和渐变本身不是缺图或低分辨率。
