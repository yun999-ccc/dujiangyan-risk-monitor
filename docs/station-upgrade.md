# 八类虚拟监测站

原监测盒只采集积水，现升级为八类场景。网页不代表一个实体盒子能检测所有灾害，也没有接入真实设备或实时权威预警。

## 八类采集内容

| 场景 | 主输入 | 配套字段与证据 |
|---|---|---|
| 积水 | 模拟水深 | 涨退速度 |
| 冰雪结冰 | 模拟路面温度 | 表面湿度、路面情况、结冰巡查、积雪厚度背景 |
| 雷电 | 模拟外部预警等级 | 有效期、原始发布时间；不采集动画频率或现场人数 |
| 大风 | 模拟基础风速 | 持续时间、来向、设施类型、巡查、阵风峰值背景 |
| 高温 | 模拟温度 | 相对湿度、遮阴、高温持续背景 |
| 森林火险 | 人为设定的演示指数 | 模拟环境温度、湿度、风速、近期降雨、烟火巡查 |
| 滑坡 | 模拟位移变化 | 累计降雨、边坡巡查、模拟外部信息 |
| 泥石流 | 模拟小时雨强 | 前期雨量、沟道异常巡查、模拟外部信息 |

背景字段标注“不参与等级计算”。火险指数不伪装成传感器读数；外部预警不声称已接入气象部门；巡查是手动模拟证据。默认演示阈值未经点位标定，不能用作实际预警标准。

## 操作

1. 进入 `device.html`，选择八类采集场景。每类有固定演示点位、独立草稿、质量与本机上报记录。
2. 修改主值、配套字段与质量，点“上报一次”。输入尚未上报时显示“参数待上报”。
3. 示例按钮会填入演示条件；冰雪的高风险示例同时填“发现结冰”，不是用低温直接认定结冰。
4. 可为明确选择的多个点位分别开启2秒定时上报。顶部显示活动点位数，蓝点标识正在上报的点位；切换场景不会偷偷停止其他点位。
5. 可停止当前点位或停止全部。刷新页面保留草稿和本机历史，但不会自动恢复定时发送。连接模式切换/断连时停止定时发送，需重新主动启动。
6. 同浏览器同源联调时，主监测页接收主值、配套字段和巡查结果；收到采集输入会退出监测轨迹回放，以免旧轨迹覆盖采集数据。灾害动画不会因此自动启动。
7. 终端可展开“判断依据与来源”，查看点位编号、来源类型、原始采集/发布时间和配套字段；确认不解除风险。

## 时效与故障

模拟传感器每次采集有新时间；停止上报超过10秒显示未知。数据缺失或过期也显示未知，保留历史有效等级。雷电自动转发保留原始发布时间，不重复发布新预警；其信号有效期与10秒上报链路时效分开检查。

各点位独立保存，停止积水不影响仍在上报的大风。森林烟火巡查不会因指数下降自动清除；低温仅提示结冰核查。动画的火焰倍率、泥流速度/宽度、滑移距离不进入采集接口。

## 云端升级

实际云项目尚未配置，未完成真实跨设备验收。已创建项目者：先执行001迁移，再执行 `supabase/migrations/202610160002_eight_stations.sql`；如果001已执行，只执行002，不重复创建旧表。原场景和账号继续使用。

新接口 `sw_submit_observation` 由数据库校验点位、字段类型、量程和来源，用固定演示规则判断八类状态。采集记录写入 `sw_station_samples`，提醒与确认继续使用既有表。旧 `sw_submit_water` 保留兼容，但新网页使用通用接口。采集账号只可上报，不能修改成员、阈值或确认提醒。

八类云端采集记录不被监测页共享心跳覆盖；旧值和重复nonce不能覆盖其他点位。云端动画时钟和河谷演算仍未同步，不能用读数联通冒充动画已同步。

## 字段与规则维护

`src/station-model.js` 定义八类字段与本机规则接入；SQL目录由同一字段定义生成。修改字段后运行：

```sh
node scripts/build-station-migration.mjs
node scripts/build-station-migration.mjs --check
```

未部署的新迁移可重新生成；已经执行002的真实项目以后应另建增量迁移，不直接改历史数据库。当前测试项目仍未实际接入。

本机测试会比较数据库目录与网页定义，并验证96组阈值/质量组合和额外巡查条件等级一致。测试不证明真实灾害预测准确。
