# 四类风险变量与动态验收

范围：竞赛视觉演示；不是人体热风险、燃烧、边坡稳定性或泥石流动力学求解。

## 控制与过程

地图旁显示主监测输入、辅助输入和独立演示参数。滑块与数值输入使用原状态对象，顶部、地图旁和下方播放入口共用效果时钟，避免把推进监测时钟误认为播放动画。动态开关、状态、时间线和主体/源区/全范围入口都在地图旁。滑坡和泥流可以勾选跟随移动主体；跟随只平移目标与相机以保留观察角度，手动拖动退出跟随。首次选择会在几何准备好后定位主体。

| 风险 | 输入 | 画面规则 |
|---|---|---|
| 高温 | 环境温度、湿度、遮阴；时长、视觉倍率 | 温度控制热表面色与热浪强弱；遮阴将假定视觉强度乘0.45。湿度是监测背景，不伪造体感或个人中暑概率。热浪为透明上升纹理，不是背景光学折射求解。 |
| 林火 | 火险指数、湿度、巡查、背景风；火险/火情模式、假定半径、增长、风向、时长 | 指数不自动起火；独立火情模式需主动播放。生成火焰与烟雾素材用于粒子和变形材质；范围按手动半径及增长演示。风从来向的相反方向吹走烟雾。结束保留假定残迹，不清除监测与巡查。 |
| 滑坡 | 位移与累计雨量；滑移距离、时长 | 监测输入不自动触发土体。土体沿DEM示意下坡路径移动，源区与移动土体分别显示。表面细分采样贴地，主体镜头按实际边界取景。结束保留土体，回到起点清除演示。 |
| 泥石流 | 雨强与前期雨量；假定流速、宽度、含固比、时长 | 雨量不直接计算发生与速度。前沿按速度和时间推进，并在示意路径末端停止；材质与颗粒表达流动，不代表厚度、流量或质量守恒。正常深度测试，不通过覆盖所有对象伪造可见性。 |

参数均有输入边界，零时长不启动；零滑移距离无土体运动，零泥流速度无前沿推进。没有有效下坡路径不生成运动通道。暂停/未知数据冻结同一阶段，拖动时间线可以复现；过程结束不解除风险。

## 素材

四张PNG来自Codex内置绘图工具，具体模型版本未向工具公开。素材目录与提示词见 `assets/effects/README.md`。火焰和烟雾检查了真实alpha通道，不是黑色矩形背景。土层和泥浆有不同表面细节。热浪纹理由程序生成。素材按风险加载，并显示加载问题，不让其他页面提前下载整套图片。

林地、火源、土体体积、颗粒与影响范围为示意，不是现场清单。地形沿用公开DEM与现有显示高程约定，未新增测绘精度。

## 检查

- 同一镜头下比较多个时间点的主体像素和状态变化；检查实际截图，不能仅凭time或moving标志通过。
- 主读数与新面板精确输入双向一致；可选火情、零输入、结束残迹与数据缺失行为独立验证。
- 顶部与地图旁播放/暂停共同变化；暂停签名冻结；低中高强度与变量作用检查。
- 390×844视口控制可见，无横向溢出；减少动态默认关闭播放，但允许时间线查看静态阶段。
- 回归冰雪、大风、雷电和积水；运行完整逻辑测试及生产构建。
- 发布成功后读取公开版本，按实际可用浏览器核对；网络连接失败与效果失败分别记录。

软件GPU截图和手机视口不能证明真实手机GPU性能，也不能证明工程物理准确性。

## 高温二次修订：绘图材质与背景扭曲

原版本仅使用程序噪声，且地表为不透明色盘；没有使用生成热浪图片。此次新增内置绘图生成的 `assets/effects/heat-haze-v1.png`，完整提示词及alpha核查见素材README。

- 去掉实心色盘，改为边缘不规则渐隐的透明地表提示。
- 四层透明热浪使用生成纹理作形态与扰动遮罩，读取同帧离屏场景背景形成屏幕空间局部扭曲。它是折射视觉近似，没有求解空气折射率、垂直温度梯度或能量传递。
- 节点原坐标保留；选取800米以内最近的已收录道路作视觉锚点，并显示道路名称和距节点距离。当前锚点距节点约110米。这个距离不是监测覆盖半径，不能视作道路实测温度。
- 地图旁可调环境温度、相对湿度背景、遮阴、演示时长、视觉倍率、上升视觉速度；增加30/38/45℃快捷对比。湿度不参与虚构人体热风险计算。
- 温度20℃时热浪强度为零；零视觉倍率、零上升速度或零时长禁止播放；静态时间线仍可查看阶段。暂停冻结同一时钟，结束移除热浪，未知冻结最后有效形态。
- 仅热浪可见时增加一次场景离屏渲染，采用当前画布真实像素尺寸；不通过降低分辨率掩盖性能开销。其他风险继续单次主场景渲染。实际手机GPU帧率仍需实机检查。

专项验收：`tests/browser/heat-effects.spec.js` 检查素材ready、同镜头像素差、温度与遮阴联动、真实背景采样启用、暂停像素冻结、零输入与数据未知、390px布局；`process-effects.spec.js` 回归四类主体。
