# 积水、冰雪、雷电、大风：控制与连续效果

本次沿用已安装的 threejs-animation、threejs-shaders、threejs-spatial-data、threejs-testing 技能。改动针对可操作性和连续画面；没有新增现场校准资料。已有四项生成素材保留，这四项采用代码原生水面、闪电几何、旗布和雪粒子，避免用平面图片代替可旋转的三维过程。

| 风险 | 地图旁控制 | 可查看过程 | 边界 |
| --- | --- | --- | --- |
| 积水 | 峰值来水、降雨、排水、下游参考水深、排水受阻、播放倍率、时间线 | 整个局部计算区的水深、流速、岸外覆盖和道路积水；流线与微波纹开关 | 沿用局部惯性演算及水量收支；河床、堤岸、排水均缺少实测校准。详细来水时长与断面参数仍在高级设置。 |
| 冰雪 | 路温、路面情况、覆盖率、雪厚、演示时长、形成示意、飘雪、增长开关 | 手动增长时覆盖率及雪厚随演示时间推进；飘雪与反光使用同一时钟；道路近景 | 增长为指定时长内线性示意，不是热力学结冰或降雪累积模型；湿度不生成冰面。 |
| 雷电 | 频率、持续时间、类型、区域、距离、视觉档位、种子、事件状态、播放/回放/单次 | 根据相同种子调度同一批事件，局部短暂放电；暂停可查看静态形态 | 未应用配置禁止播放旧参数。视觉档位不表示实测电流；人员只参与应急说明。 |
| 大风 | 风速、时长、来向、可选阵风、视角、播放倍率、时间线 | 连续风迹、固定边缘旗布变形、树冠摆动；正面与侧面观察 | 沿用确定性视觉响应，不是风场或结构力学求解。 |

四项顶部播放都路由至各自时钟。冰雪播放保留已选近景；其余原有定位行为保留。地图旁搬移原控件，不建立另一套参数副本。切换风险还原控件位置，只有当前风险的控制区可见。

## 检查

- `tests/hazard-effects.test.mjs`：显式冰雪门控、增长端点、零覆盖、零时长、干燥路面及可重现性。
- `tests/browser/remaining-effects.spec.js`：同镜头不同阶段像素变化，雪粒子连续变化与暂停冻结；未知门控；未应用雷电配置；河段实际参数；手机无横向溢出及反复切换唯一控件。
- 原有 hazard-effects / hydraulic / lightning / wind 浏览器回归；风测试新增等待下一渲染帧，避免参数更新后读取上一帧的同一时间戳。
- 软件GPU浏览器测试与390px视口不等于实机手机GPU性能验收。
