# 山川守望：操作手册（网页演示版）

## 三个网页

- 监测模拟：`./`，八类风险的三维展示、模拟变量、判断依据、变化记录。
- 虚拟监测站：`device.html`，八类独立模拟采集、来源标识、巡查与质量、手动或2秒定时上报。详见 `docs/station-upgrade.md`。
- 警示终端：`terminal.html`，显示八类状态、数据时效、确认记录，可主动启用提示音。

所有设备、读数与阈值是演示。三维水系底图不等于计算水面。龙溪河局部水动力使用假定河床、堤岸与排水条件，不能预测真实淹没。其计算结果不冒充监测盒读数。

## 八类风险

选择左侧点位，查看右侧参数与依据；下方的现象控制区独立控制播放/暂停、时间线及观察视角。数据异常不表示风险解除。

| 风险 | 操作重点 | 边界 |
|---|---|---|
| 积水 | 区域点位可输入水深；河谷局部演算调整上游来水、降雨、排水；播放、暂停、定位查看水面 | 两类模型用途不同，均未实测标定 |
| 冰雪结冰 | 设置路面情况、巡查、积雪覆盖和雪深，主动启用形成示意并播放 | 低温不等于结冰，形成示意不代替巡查 |
| 雷电 | 选择模拟外部预警；独立控制放电频率、视觉强度和持续时间，再播放 | 闪电位置和通道为示意，不是雷击预测 |
| 大风 | 风速、持续时间、风向，可选阵风；播放观察风迹、旗布、树冠 | 不计算建筑或树木破坏 |
| 高温 | 温度、遮阴、持续时间；启动后选择热浪近景；30/38/45℃对比，增强热浪可开关 | 热浪纹理为强化表达，不是气温场测量，不诊断中暑 |
| 森林火险 | 指数是监测输入；主动启动火情演示才有火焰，调节火势、烟量与时间 | 火险高不自动起火；火焰是演示，巡查记录独立 |
| 滑坡 | 默认看周边道路；选择条带预览、启动运动，调节滑移与时间；可查看道路全貌 | 下坡路径是公开DEM采样假定，不是真实滑坡范围 |
| 泥石流 | 默认路径总览；主动启动后看前锋近景，调整速度、宽度、含固比例、持续时间 | 曲面、滚石、沉积为视觉演示；非实测沟道，无完整流变/守恒模型 |

## 三页联调

1. 用同一浏览器打开同一网站的三个标签页。不同浏览器、隐私窗口、不同手机不共享本地数据。
2. 打开虚拟监测站，先选择积水，设置水深，如35cm，点击“上报一次”。终端与监测页更新水位和演示等级。其他七类可分别选择并上报，各自保存草稿与记录。定时上报每2秒一次，浏览器后台节流可能延迟。
3. 在终端点击“确认已阅”。警示仍保留；确认不修改读数或清除风险；已打开的监测页会记录本机已阅事件。该等级变化产生新的提醒，需要再次确认。
4. 设置“传感器故障演示”后上报，监测页与终端显示未知。恢复有效质量并重新上报才恢复判断。
5. 终端“暂停接收”立即标为未知并保留末次值；恢复时重新读取。停止所有上报源超过10秒也标为超时未知。
6. 监测页面打开时每2秒发布当前演示状态；监测盒读数保留采集时间，转发不会刷新其时效，超过10秒标为未知；监测盒定时上报也可独立运行。演示时避免同时在两个页面对同一水位连续调值，以免互相覆盖。不要在多个监测标签页运行不同情景。
7. 提示音需主动开启；系统静音、浏览器限制、后台或息屏时可能无声，不能用作安全报警。

## 保存与导出

本地记录保存在浏览器localStorage；清除网站数据会删除。监测页“导出记录”导出情景与操作数据；终端确认记录单独保存在本机，不在该导出内。已提供可配置的云端接入代码，但没有实际云项目，尚未完成真实跨设备验收；云端动画时间线和河谷演算仍未同步。浏览器存储不可用时，上报会显示失败。

## 网络与异常

页面需要先加载成功。当前没有Service Worker，不承诺离线重开或后台持续运行。保留末次值不代表有硬件离线报警。图像/地形加载失败时检查网络并重试；如模型不可见，切换总览/近景、检查动态效果开关和播放状态。以页面的异常提示为准，不能从“未显示灾害”推断现场安全。
