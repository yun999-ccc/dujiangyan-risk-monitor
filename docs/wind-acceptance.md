# 大风演示实施与验收

范围：受风视觉演示，不是CFD、旗布力学、树木稳定性或倒塌计算。

## 控制与时间规则

- 基础风速0–35 m/s、持续0–3600模拟秒、来向0–360°集中在大风控制面板，滑块与精确输入共用原节点数据。30/60/180秒与四个方向提供快捷输入。
- 可选假定阵风默认关闭。峰值不得低于基础风速或超过35 m/s，间隔4–60秒。用平滑周期脉冲表达增强与回落；并非实测阵风波形。0 m/s定义为关闭受风过程，阵风也不启动。
- 1/3/5/10倍只改变时钟推进；暂停冻结当前阶段，拖动时间线按同一过程重建画面。回到起点以当前设置新建过程。
- 过程开头与结尾各2模拟秒平滑变化；时长不足4秒时各缩为时长的一半。到终点风迹消失、旗布及树冠回落，但基础风速与巡查记录保留。动画时钟与监测时钟独立。
- 播放中变更风速或来向，在2模拟秒内过渡并记录本次过程；暂停时更新静态阶段。缩短时长时当前时间不超过新终点。数据缺失停止播放并保留最后有效画面。
- 风险提示沿用基础风速及巡查规则。可选阵风峰值是现象层假定输入，不自动改写监测读数或清除巡查记录。

## 场景

连续渐隐风迹、固定旗杆与旗布一边的网格变形、固定树干基部的上部和树冠响应。来向表示风从哪里来，北风吹向南、东风吹向西。风迹位移按模拟风速积分，轨迹沿地形背景表达方向；旗布和树冠响应系数为人为视觉映射。

默认旗布近景，并提供树冠近景和全场景。近景隐藏会挡住对象的风险球标记，保留侧栏读数和状态。对象位置及尺寸为示意，并避让已收录道路和水面；不能视为真实设备或树木清单。

## 验收矩阵

| 项目 | 检查输入与预期 | 验证方式 |
|---|---|---|
| 强弱变化 | 0/5/15/30 m/s同一时刻：速度、风迹数量、旗布伸展和树冠摆幅递增；0时静止 | 单元 + 浏览器 |
| 时间 | 0/30/120秒；0时不可启动，结束时无风并停止播放 | 单元 + 浏览器 |
| 方向 | 0/90/180/270°的来向与吹向一致 | 单元 + 浏览器 |
| 阵风 | 基础5、峰值30、间隔12秒：6秒达到峰值，12秒回落；关闭时保持基础 | 单元 + 浏览器 |
| 固定约束 | 旗布靠杆边缘误差<3mm（渲染坐标检查，不是测绘精度），树根坐标不变 | 单元 + 浏览器 |
| 暂停回放 | 暂停签名不变；同一参数、历史与时刻得到同一过程 | 单元 + 浏览器 |
| 变更与结束 | 播放中两秒过渡；缩短时间正确裁限；结束不清除输入或松动巡查记录 | 单元 + 浏览器 |
| 可辨认 | 强风旗布近景：桌面宽度>40像素且在画面内，手机宽度>16像素；树冠桌面近景高度>45像素 | 实际相机投影 + 截图复查 |
| 数据未知 | 冻结最后有效画面，播放和输入禁用 | 浏览器 |
| 窄屏与减少动态 | 390×844不溢出；减少动态默认关闭播放，但时间线仍能查看静态阶段 | 浏览器 |
