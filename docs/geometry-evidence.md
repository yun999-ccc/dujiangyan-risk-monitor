# 第一项：真实几何与数据依据

状态：已完成当前数据清点和追溯；**真实几何尚未通过验收**。这个文件不是测量成果，也不是现场准确性认证。

## 已确认的项目事实

- 地形来自已打包的Mapzen Terrain Tiles，下载元数据为2026-10-10；513×513经纬度采样网格，区域中部采样间距约50.3m×50.0m。该间距不是位置或高程误差。
- 河谷演算为96×96、16m插值网格，没有增加原始测绘细节。当地源数据的垂直精度、裸土属性、垂直基准和测量年代尚未核实。
- 默认河槽48m宽、3m深；人工平滑纵剖面、去除局部反坡并构造岸外96m过渡。默认条件下1765个单元与公开DEM差值超过1cm，面积45.184ha；最大绝对差值约50.917m。差值不是现场误差，也不是建模准确度。
- 全区域420条建筑轮廓：1条使用高度标签，233条按楼层×3m推算，186条默认12m。高度标签亦未经现场核验。模型另含3—90m高度限制、基座补齐与1.8倍展示高度。
- 局部公开数据含8条道路，含桥梁标签；无建筑way记录。2026-10-12对同一区域重新查询OSM，仍返回8条道路、0条建筑way。不能据此认定现场无建筑。
- 复查不替换原始数据。记录包括端点、范围、时间、响应哈希和要素ID，见`public/data/local-osm-check.json`。

## 可检查的网页功能

地图下方“几何数据依据”展示公开、推算、缺失和未核实内容。进入河谷演算后，可切换假定计算地形、公开DEM背景和修改分布；核查模式隐藏水面、流线、观察点与道路，不修改计算数组。东西向网格剖面可拖动或定位最大修改处。导出包含已应用参数、原始/计算高程、差值和剖面坐标。

图中的公开DEM背景仍是从打包高程插值到计算网格的结果，**不是原始测绘点或实测河床**。东西向剖面不一定垂直河道，不应当作实测河道横断面。高程数据和差值使用原始米；三维核查显示仍有1.8倍夸张，这个阶段没有完成第三项比例一致性整改。

## 第一项通过需要的资料

| 资料 | 必须保留的信息 | 当前状态 |
| --- | --- | --- |
| 岸外地形 | 原始文件、采集日期、分辨率、水平/垂直基准、精度或质量报告、裸土处理方法 | 部分公开背景；工程适用性未核实 |
| 河床断面及纵剖面 | 断面编号、坐标、每点高程、采集日期、测量方法、基准；覆盖控制水流的河段 | 缺失 |
| 堤岸与护岸 | 岸顶/堤顶控制高程、缺口与越岸通道位置、采集日期与基准 | 缺失 |
| 道路/桥梁/建筑 | 路面高程、桥孔及桥墩、阻水结构平面位置/高程；建筑覆盖核查 | 未核实 |
| 排水设施 | 排水口位置、控制高程、管网或排水能力的依据 | 缺失 |

可接受测绘成果或提供者许可使用的可靠原始资料。截图、图片上的手工描线、网上同名“龙溪河”的其他流域资料、历史灾情的文字描述，不能直接替代本河段当前实测几何。开源模型代码也不能替代这些输入。

取得资料后，应先核对位置、日期、许可和坐标/高程基准，再做转换、覆盖范围和断面一致性检查，并保留原文件与转换记录。不能把历史断面默认当作当前河床，也不能未经确认将卫星DEM的河面当作水下河床。

本轮检查了Terrain Tiles官方资料、HEC-RAS地形要求、当地黄央沟研究及OSM指定片区查询。找到了公开背景和历史研究，**没有取得可直接替换本河段当前河床/堤岸的实测断面**。这不证明资料不存在。

## 可重复核查

运行`npm run audit:data`重新生成清单。构建和逻辑测试前会自动生成，文件SHA-256用于识别数据版本，**不证明资料质量**。逻辑测试验证分类、坐标、差值及未核实状态；浏览器测试验证三维核查切换、参数联动、导出和窄屏布局。这些检查不等于现场校准。
